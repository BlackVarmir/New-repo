# 🤖 Telegram Speech-to-Text Bot

Телеграм бот для распознавания речи из голосовых сообщений и аудио файлов.

## ✨ Возможности

- 🎤 **Распознавание голосовых сообщений** - отправьте голосовое сообщение и получите текст
- 🎵 **Поддержка аудио файлов** - работает с MP3, WAV, FLAC, OGG и другими форматами
- 🌍 **10+ языков** - русский, английский, немецкий, французский, испанский и др.
- 🔄 **Автоматическая конвертация** - бот сам преобразует аудио в нужный формат
- ⚡ **Быстрое распознавание** - результат за несколько секунд
- 💾 **Без сохранения данных** - все временные файлы удаляются после обработки

## 🚀 Быстрый старт

### 1. Создание бота в Telegram

1. Откройте Telegram и найдите [@BotFather](https://t.me/botfather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям: укажите имя и username бота
4. Получите токен бота (например: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)
5. Сохраните токен - он понадобится для запуска

### 2. Установка зависимостей

#### Системные зависимости

**Ubuntu/Debian:**
```bash
sudo apt-get update
sudo apt-get install -y portaudio19-dev python3-pyaudio ffmpeg
```

**macOS:**
```bash
brew install portaudio ffmpeg
```

**Windows:**
- Установите [FFmpeg](https://ffmpeg.org/download.html)
- Добавьте FFmpeg в PATH

#### Python зависимости

```bash
pip install -r requirements.txt
```

### 3. Настройка

Создайте файл `.env` в корне проекта:

```bash
cp .env.example .env
```

Откройте `.env` и вставьте ваш токен:

```bash
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
```

### 4. Запуск бота

```bash
python telegram_bot.py
```

Или с использованием переменной окружения напрямую:

```bash
export TELEGRAM_BOT_TOKEN="ваш_токен"
python telegram_bot.py
```

После запуска вы увидите:
```
INFO - Starting Speech Recognition Bot...
INFO - Bot is running...
```

Готово! Найдите вашего бота в Telegram и начните использовать.

## 🔧 Продвинутая настройка

### Запуск в фоновом режиме (Linux)

С использованием `nohup`:
```bash
nohup python telegram_bot.py > bot.log 2>&1 &
```

С использованием `screen`:
```bash
screen -S telegram_bot
python telegram_bot.py
# Нажмите Ctrl+A, затем D для отсоединения
```

С использованием `systemd`:

Создайте файл `/etc/systemd/system/speech-bot.service`:
```ini
[Unit]
Description=Telegram Speech-to-Text Bot
After=network.target

[Service]
Type=simple
User=your_user
WorkingDirectory=/path/to/New-repo
Environment="TELEGRAM_BOT_TOKEN=your_token"
ExecStart=/usr/bin/python3 telegram_bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```

Запустите службу:
```bash
sudo systemctl daemon-reload
sudo systemctl enable speech-bot
sudo systemctl start speech-bot
```

### Использование с Docker

Создайте `Dockerfile`:
```dockerfile
FROM python:3.10-slim

RUN apt-get update && apt-get install -y \
    portaudio19-dev \
    ffmpeg \
    && rm -rf /var/lib/apt/lists/*

WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

CMD ["python", "telegram_bot.py"]
```

Создайте `docker-compose.yml`:
```yaml
version: '3.8'

services:
  bot:
    build: .
    environment:
      - TELEGRAM_BOT_TOKEN=${TELEGRAM_BOT_TOKEN}
    restart: unless-stopped
```

Запустите:
```bash
docker-compose up -d
```

## 🐛 Решение проблем

### Бот не отвечает

**Проблема**: Бот запущен, но не отвечает на сообщения.

**Решение**:
1. Проверьте, правильно ли указан токен в `.env`
2. Убедитесь, что токен не содержит лишних пробелов
3. Проверьте интернет соединение
4. Посмотрите логи на наличие ошибок

### Ошибка "No module named 'telegram'"

**Проблема**: Не установлена библиотека python-telegram-bot.

**Решение**:
```bash
pip install python-telegram-bot>=20.0
```

### Ошибка распознавания речи

**Проблема**: Бот не может распознать голосовое сообщение.

**Возможные причины**:
- Плохое качество аудио
- Сильный фоновый шум
- Неправильно выбран язык
- Слишком тихая или быстрая речь

**Решение**:
1. Проверьте выбранный язык командой `/language`
2. Говорите четко и не слишком быстро
3. Избегайте фонового шума
4. Попробуйте записать заново

### Ошибка конвертации аудио

**Проблема**: Ошибка при обработке MP3 или других форматов.

**Решение**:
Убедитесь, что установлены `pydub` и `ffmpeg`:
```bash
# Установка pydub
pip install pydub

# Установка ffmpeg
# Ubuntu/Debian:
sudo apt-get install ffmpeg

# macOS:
brew install ffmpeg
```

### Бот падает с ошибкой памяти

**Проблема**: Недостаточно памяти при обработке больших аудио файлов.

**Решение**:
- Telegram ограничивает размер голосовых сообщений (обычно до 20 МБ)
- Разбейте длинные записи на части по 1-2 минуты
- Убедитесь, что на сервере достаточно RAM (рекомендуется минимум 512 МБ)

## 🔒 Безопасность

### Рекомендации:

1. **Не публикуйте токен бота** - добавьте `.env` в `.gitignore`
2. **Ограничьте доступ** - используйте whitelist пользователей для приватного бота
3. **Регулярно обновляйте зависимости** - следите за обновлениями безопасности
4. **Используйте HTTPS** - для веб-хуков (если используете)
5. **Мониторинг** - отслеживайте необычную активность

### Добавление whitelist пользователей

Добавьте в `.env`:
```bash
ALLOWED_USERS=123456789,987654321
```

Модифицируйте бота для проверки пользователей (опционально).
